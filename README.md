# Abdul Rahman Rahimi

**Software Developer & Geospatial Analyst** · Founder of **Rahimi Tech Solution** · Vancouver, Canada

I build web GIS applications and full-stack business software. My GIS work is interactive maps and dashboards for health and NGO programmes in Afghanistan, covering everything from clinic locations to M&E indicators. My software work is ERP, inventory, accounting and management systems that businesses in Afghanistan and Canada use every day. Many of these systems are bilingual (English, Pashto, Dari) and handle several currencies.
